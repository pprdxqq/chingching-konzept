# MY ASIA — Kelsterbach

A responsive, static restaurant website for MY ASIA, Bergstraße 38, 65451 Kelsterbach.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. GitHub Pages will publish the site at the URL shown in Settings → Pages (usually `https://pprdxqq.github.io/chingching-konzept/`).

No build step or secrets are required. The site is plain HTML, CSS and JavaScript.

## Features
- Responsive mobile-first layout
- German/English language toggle
- Menu category filters
- Click-to-call ordering and Google Maps directions
- Reduced-motion support, semantic sections and SEO metadata

## Content note
Restaurant details and the displayed sample dishes/prices are based on the restaurant's published website at https://myasiakelsterbach.de/. The menu is intentionally a selection, not a replacement for the restaurant's complete current menu. Opening times can vary on public holidays; guests should call to confirm.
